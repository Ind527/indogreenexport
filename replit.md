# Premium Turmeric Export Website

## Overview

This is a static website for a premium agricultural export company specializing in turmeric and banana leaf products. The website showcases the company's products, services, and capabilities to potential international clients. Built with vanilla HTML, CSS, and JavaScript, it features a modern, responsive design with smooth animations and professional presentation.

## User Preferences

Preferred communication style: Simple, everyday language.

## System Architecture

### Frontend Architecture
- **Static Website**: Pure HTML, CSS, and JavaScript without any backend framework
- **Responsive Design**: Mobile-first approach with CSS Grid and Flexbox
- **Modern CSS**: Uses CSS custom properties (variables) for consistent theming
- **Vanilla JavaScript**: No frameworks, focusing on performance and simplicity
- **Progressive Enhancement**: Core functionality works without JavaScript

### Styling Strategy
- **CSS Variables**: Centralized color scheme and design tokens
- **Component-Based CSS**: Modular CSS structure for maintainability
- **Animation System**: CSS animations for floating elements and smooth transitions
- **Typography**: Google Fonts (Poppins) for professional appearance

## Key Components

### Navigation System
- **Responsive Navigation**: Hamburger menu for mobile devices
- **Active State Management**: Dynamic highlighting of current page
- **Smooth Scrolling**: Enhanced user experience with smooth page transitions

### Page Structure
- **Multi-page Architecture**: Separate HTML files for different sections
  - `index.html`: Homepage with hero section and company overview
  - `products.html`: Product catalog and specifications
  - `gallery.html`: Visual showcase of facilities and products
  - `about.html`: Company information and background

### Interactive Features
- **Gallery Filter System**: Category-based product filtering
- **Modal System**: Image lightbox functionality
- **Contact Form**: Email integration for client inquiries
- **Floating Animations**: Decorative leaf elements with CSS animations

### Asset Management
- **Image Assets**: Company logo and product images stored in `attached_assets/`
- **External Dependencies**: Font Awesome icons and Google Fonts via CDN
- **Optimized Loading**: Efficient asset loading for performance
